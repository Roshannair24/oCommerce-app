## Deliverables

### Test 1 – Landing page

#### Hero

- The reviews tab is currently linked to the catalog page, as there is no review data for now.
- Helvetica is used as the CTA label font instead of "Font Label Caps Strong", as the latter is unavailable in the Shopify font library.

#### Drop teaser (left panel)

- A minutes tile has been added to the countdown timer. It was not specified in the Figma file.
- The countdown timer can be set to a desired date, along with a custom message shown once the timer completes.

#### Email notification (right panel)

- On successful addition, a thank-you message is returned.

#### Display text section

- Pinyon Script is used as the primary font instead of the "Title Display Cursive" font, as the latter is unavailable in the Shopify font library.

### Test 2 – Product card

The new product card is wired in the catalog page.

#### Quick add

- Failed requests and double clicks are not handled.
